# X Meme Library

Drop original images, GIFs, or MP4s for Vladinator posts in this folder.

Supported working set:

- `.png`, `.jpg`, `.jpeg`, `.webp`
- `.gif`
- `.mp4`

The future X publisher will choose from this directory, remember recent file hashes, and avoid immediate repeats. Keep files under your control and only add media you are allowed to publish.

Suggested filenames:

```text
vladmaxxing-01.png
green-candle-02.gif
backrooms-hood-03.mp4
```

`manifest.json` is optional metadata for tags or an explicit caption angle. Files without a manifest entry remain eligible for random selection.
